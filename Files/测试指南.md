# Quipster 手动测试指南

## 测试环境准备

### 前置条件

- Node.js 18+ 已安装
- 项目依赖已安装（`cd frontend && npm install`）
- 开发服务器已启动（`npm run dev`）

### 测试账号

| 用途 | 邮箱 | 说明 |
|------|------|------|
| 正常用户 | 需自行注册 | 使用同济邮箱注册 |

### 1. 认证模块

#### TC-AUTH-001: 用户注册

| 项目 | 内容 |
|------|------|
| 前置条件 | 无 |
| 测试步骤 | 1. 访问 `/register`<br>2. 输入同济邮箱（xxx@tongji.edu.cn 或 xxx@stu.tongji.edu.cn）<br>3. 输入密码（至少6位）<br>4. 输入昵称（2-20字符）<br>5. 点击注册按钮 |

## 自动化测试

### 运行测试

```bash
cd frontend

# 运行测试（监听模式）
npm run test

# 运行测试（单次执行）
npm run test:run

# 运行测试并生成覆盖率报告
npm run test:coverage
```

### 测试文件位置

| 类型 | 位置 |
|------|------|
| 测试配置 | `frontend/vitest.config.ts` |
| 测试设置 | `frontend/src/test/setup.ts` |
| 组件测试 | `frontend/src/**/*.test.tsx` |
| 单元测试 | `frontend/src/**/*.test.ts` |

### 已覆盖的测试

| 模块 | 文件 | 测试内容 |
|------|------|----------|
| LoadingSpinner | `LoadingSpinner.test.tsx` | 渲染、默认高度、自定义高度 |
| EmptyState | `EmptyState.test.tsx` | 消息渲染、自定义图标 |
| authSlice | `authSlice.test.ts` | clearError、updateUser、初始状态 |
