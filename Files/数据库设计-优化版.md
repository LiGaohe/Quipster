# Quipster 数据库设计优化版

## 1. 设计原则

本系统数据库设计遵循以下原则：

* 数据一致性：通过主键、外键与约束保证数据完整性
* 隐私分级：区分公开数据与私密数据，支持权限控制
* 高可扩展性：支持未来功能扩展
* 高性能：结合索引与缓存优化查询效率
* 简洁性：减少表数量，优化数据库结构

系统采用 **PostgreSQL** 作为主数据库。

## 2. 隐私分级模型

系统将数据分为三类：

* 公开数据(Public)：所有用户可见(如动态内容)
* 受限数据(Protected)：仅好友或匹配用户可见
* 私密数据(Private)：仅用户本人或系统可访问
  通过字段**visibility** 实现访问控制。

## 3. 外键命名规范

本系统外键命名遵循以下规范：

* 引用用户表(users)的外键统一使用`_user_id` 后缀，如`creator_user_id`、`sender_user_id`
* 引用其他表的外键使用`_id` 后缀，如`post_id`、`conversation_id`
* 多对多关系表使用复合主键，外键命名与被引用表字段名一致

## 4. 数据表设计

### 4.0 字段限定符说明

在同一张表中，部分字段仅在特定类型下有效，通过以下限定符区分：

| 限定符 | 含义 | 说明 |
| ------ | ---- | ---- |
| 仅动态 | `type = 'post'` 时有效 | 动态可以附带图片和可见性设置，评论不支持 |
| 仅评论 | `type = 'comment'` 时有效 | 评论需要关联所属动态或父评论，主帖无需这些字段 |
| 仅主帖 | `type = 'post'` 时有效 | 树洞/活动的顶层内容，支持标题、标签等属性 |
| 仅活动 | `activity_type = 'event'` 时有效 | 线下/线上活动专有字段 |
| 仅任务 | `activity_type = 'study_task'` 时有效 | 学习任务专有字段 |
| 内部记录 | 对外不展示用户身份 | 前端不展示发布者，但后端存发布者id |

**设计目的**：通过类型字段实现继承式设计，减少表数量，同时保持数据结构清晰。

### 4.1 用户表(users)

| 字段名        | 类型                         | 描述                                         |
| ------------- | ---------------------------- | -------------------------------------------- |
| id            | UUID PRIMARY KEY             | 用户ID（与Supabase Auth集成）                |
| email         | VARCHAR(255) UNIQUE NOT NULL | 校园邮箱(私密)                               |
| password_hash | TEXT                         | 密码哈希(私密)                               |
| nickname      | VARCHAR(50) NOT NULL         | 昵称(公开)                                   |
| avatar_url    | VARCHAR(500)                 | 头像URL(公开)                                |
| gender        | VARCHAR(10)                  | 性别：male/female/other(受限)                |
| major         | VARCHAR(100)                 | 专业(受限)                                   |
| grade         | VARCHAR(20)                  | 年级(受限)                                   |
| bio           | TEXT                         | 个人简介(公开)                               |
| credit_score  | INT DEFAULT 100              | 信用积分(私密)                               |
| visibility    | INT DEFAULT 1                | 可见性控制：0=Private, 1=Protected, 2=Public |
| status        | VARCHAR(20) DEFAULT 'active' | 账户状态                                     |
| created_at    | TIMESTAMPTZ DEFAULT NOW()    | 创建时间                                     |
| updated_at    | TIMESTAMPTZ                  | 更新时间                                     |

**约束**：

* credit_score >= 0 AND credit_score <= 200
* gender IN ('male', 'female', 'other', NULL)

| 字段名     | 类型                                            | 描述                               |

| 字段名     | 类型                      | 描述                 |
| ---------- | ------------------------- | -------------------- |
